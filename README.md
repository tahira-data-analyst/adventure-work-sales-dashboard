# 📊 Adventure Works Sales Dashboard | Power BI

### 🔍 Project Overview
This is an end-to-end Power BI project analyzing sales performance of Adventure Works. 
The dashboard provides insights into sales, profit, customers, and products using advanced DAX and data modeling.

### 🛠️ Tools & Skills Used
- Power BI Desktop
- DAX Measures
- Data Modeling & Power Query
- Data Visualization & Storytelling
